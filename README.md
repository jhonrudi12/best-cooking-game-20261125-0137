Ember & Thyme — Bistro Rush: a complete cooking game in a desktop browser. Read the tickets on the order board, grill patties until golden, build each dish on the plate from the pantry bins, and serve the exact ticket before its patience runs out. One 2:30 shift, three hearts, combos, coins, and a head-chef star rating at the end. Keyboard + mouse, no downloads, no network — all art and sound are drawn and synthesized in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static server and open `game/index.html`.
